Changelog - SnackCheck
[1.0.0] - Versión final

## Añadido

Webhook para recibir códigos de barras.
Validación del código de barras.
Consulta de productos mediante Open Food Facts.
Comprobación de existencia del producto.
Comprobación de datos nutricionales.
Clasificación mediante semáforo nutricional.
Clasificación mediante Nutri-Score.
Combinación de ambas clasificaciones.
Generación del mensaje final mediante Groq.
Respuestas para los diferentes casos de error.
Pruebas del workflow con diferentes códigos de barras.

## Corregido

Gestión de errores HTTP de Open Food Facts.
Conversión de los saltos de línea generados por Groq para la respuesta final.
